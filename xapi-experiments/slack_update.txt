We’ve generated 5 scaled xAPI Statement datasets for system testing using DATASIM (yetanalytics/datasim). Sizes: tiny (~1k), small (~5k), medium (~10k), large (~50k), huge (~100k) statements. All are NDJSON (one JSON statement per line), reproducible with fixed seeds. You can find the outputs in the repo under `xapi-experiments/outputs/` (e.g. `tiny.ndjson` … `huge.ndjson`). Setup and one-command run instructions are in `xapi-experiments/README.md`.
